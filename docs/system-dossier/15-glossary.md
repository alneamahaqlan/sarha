# الفصل الخامس عشر — ملحق: قاموس المزايا والمصطلحات

> [⬅ العودة للفهرس](00-index.md) · الفصل السابق: [خارطة الطريق](14-roadmap.md)

> مرجع سريع لكل المصطلحات والمزايا الواردة في المستند، مرتّبة موضوعياً. عند تكرار مصطلح في فصلٍ ما، يحيل هذا الملحق إليه.

---

## 15.1 مصطلحات النموذج والأعمال

| المصطلح | المعنى |
| --- | --- |
| **المجمع الطبي (Medical Complex)** | الوحدة الأساسية التي يراها المريض؛ قد تضمّ عدّة عيادات/تخصصات فرعية. تُسمّى داخلياً `Clinic`. |
| **العيادة الفرعية (Sub-Clinic)** | تخصص فرعي داخل المجمع، له صفحة تفصيلية عامة. |
| **سوق ثلاثي الأطراف** | منصة تربط ثلاثة أطراف: المرضى (الطلب) + المجمعات (العرض) + الإدارة (المشغّل). [الفصل 3](03-solution-three-sided.md) |
| **دولاب النمو (Flywheel)** | حلقة تعزيز ذاتي: مجمعات أكثر ← مرضى أكثر ← مجمعات أكثر. [§3.3](03-solution-three-sided.md#33-كيف-تتدفق-القيمة-دولاب-النمو) |
| **مرحلة التدشين (Pre-traction)** | المنتج جاهز ويعمل، قبل بدء الجذب التجاري والأرقام الفعلية. [§1.2](01-executive-summary.md) |
| **الخندق الدفاعي (Moat)** | ما يصعّب على المنافس التقليد: شبكة + بيانات أسعار + هوية عملاء + ولاء + كلفة تحوّل. [الفصل 11](11-moat.md) |
| **كلفة التحوّل (Switching Cost)** | صعوبة انتقال المجمع لمنصة أخرى بعد احتجاز بياناته وعملياته وعملائه. |
| **تأثير الشبكة (Network Effect)** | ارتفاع قيمة المنصة كلما زاد مستخدموها على الجانبين. |
| **محرّك النمو والولاء** | منظومة المزايا التي تكتسب وتفعّل وتحتفظ وتُربِح الانتباه. [الفصل 9](09-growth-loyalty.md) |

## 15.2 مؤشرات مالية

| المصطلح | المعنى |
| --- | --- |
| **TAM / SAM / SOM** | السوق الكلي / القابل للخدمة / القابل للوصول. [§2.3](02-problem-opportunity.md#23-حجم-السوق-tam--sam--som) |
| **MRR** | الإيراد الشهري المتكرر (مجمعات نشطة × ARPU). |
| **ARPU** | متوسط الدخل لكل مجمع. |
| **CAC / LTV / LTV-CAC** | تكلفة الاكتساب / القيمة الدائمة / نسبة صحّة النموذج (الهدف ≥ 3). [§10.7](10-business-model.md#107-اقتصاديات-الوحدة-إطار--مرحلة-التدشين) |
| **إيراد الاشتراكات مقابل إيراد الخدمات** | الأول من باقات المجمعات، الثاني = مجموع السعر الصافي للحجوزات المكتملة (مؤشر تشغيلي للمجمع). [§6.5](06-clinic-crm-operations.md#65-تتبع-قيمة-الخدمات-والتقارير) |
| **SaaS / Recurring Revenue** | برمجيات كخدمة باشتراك متكرّر / الإيراد المتكرّر المتوقّع. |

## 15.3 مزايا المريض (الموقع العام)

| الميزة | الوصف · المرجع |
| --- | --- |
| **البحث الذكي** | فلاتر (مدينة/تخصص/سعر/تقييم/مفتوح الآن) + 5 خيارات فرز. [§4.3](04-patient-journey.md#43-البحث-والفرز-الذكي) |
| **المقارنة** | مقارنة عدة مجمعات جنباً إلى جنب. [§4.4](04-patient-journey.md) |
| **الحجز الفوري (OTP)** | حجز مؤكَّد برمز تحقق + رمز مرجعي (يمكن نيابةً عن قريب). [§4.6](04-patient-journey.md#46-التحويل-الحجز-وطلب-التسعير-والسلة) |
| **التسعير متعدّد المجمعات** | طلب سعر من عدة مجمعات/مدن دفعة واحدة. |
| **السلة (Cart)** | إضافة خدمة/عرض/باقة ثم حجز/حذف؛ غير المحجوزة = سلة متروكة. [§9.4](09-growth-loyalty.md#94-السلة-واسترجاع-السلال-المتروكة) |
| **المتابعة (Follow)** | اشتراك عام بالمجمع + شرائح مخصّصة للمتابِع. [§9.2](09-growth-loyalty.md#92-المتابعة-follow--قناة-الولاء) |
| **الصفحات التفصيلية** | صفحة مستقلة لكل عرض/خدمة/باقة/طبيب/عيادة فرعية (SEO). [§4.5](04-patient-journey.md#45-ملف-المجمع-والصفحات-التفصيلية) |
| **حساب المريض** | حجوزات/مفضّلة/تسعير/سلة/متابَعون/شكاوى/أقارب. [§4.8](04-patient-journey.md#48-حساب-المريض) |
| **المساعد الذكي** | توجيه للتخصص/المجمع مع رفض الأسئلة الطبية. [§8.2](08-ai.md#82-المساعد-العام-للمريض) |

| **الهوية الموحّدة للعميل** | عميل واحد عبر المنصة بالهاتف + أسماء بديلة + توثيق. [§6.3](06-clinic-crm-operations.md#63-الهوية-الموحدة-للعميل) |
| **CRM 360°** | سجلّ عميل + وسوم محسوبة + ملاحظات + مركز عملاء. [§6.4](06-clinic-crm-operations.md#64-ملف-العميل-crm-360) |

| **السلال المتروكة** | عملاء محتملون + تواصل/تحويل + تذكير تلقائي. [§6.8](06-clinic-crm-operations.md#68-السلال-المتروكة-كعملاء-محتملين) |
| **فريق العمل والأدوار** | owner/coordinator/reception بمساءلة كاملة. [§6.9](06-clinic-crm-operations.md#69-فريق-العمل-والأدوار) |

## 15.6 الاشتراكات والمزايا (FeatureGate)

| العمود | النوع | المعنى |
| --- | --- | --- |
| `services_limit` | عدد/∞ | حد الخدمات |
| `articles_monthly_limit` | عدد/∞ | حد المقالات شهرياً |
| `ai_article_generation` | نعم/لا | توليد مقال بالذكاء الاصطناعي |
| `featured_in_search` | نعم/لا | أولوية الظهور بالبحث |
| `ai_assistant_priority` | 0/1/2 | الترتيب في المساعد |
| `google_reviews_sync` | نعم/لا | مزامنة تقييمات Google |
| `verified_badge` | نعم/لا | شارة التوثيق |
| `analytics_level` | basic/full | مستوى التحليلات |
| `quote_replies_monthly_limit` | عدد/∞ | حد ردود التسعير شهرياً |
| `banner_slots` | عدد | بانرات الصفحة الرئيسية |
| `allow_offers_packages` | نعم/لا | العروض والباقات |
| `allow_doctors_before_after` | نعم/لا | الأطباء ومعرض قبل/بعد |
| `crm_enabled` | نعم/لا | نظام CRM المتكامل (افتراضي مُفعّل) |

> **بوابات لكل مجمع** (خارج الباقة، عبر [مركز الصلاحيات](07-admin-product.md#74-مركز-الطلبات-والصلاحيات-access-center)): `cart_status` (موقوف) · `price_quote_status` (مُفعّل) · `tracking` (موقوف). التفصيل في [§10.4](10-business-model.md#104-مصفوفة-المزايا-والبوابات). حالات الاشتراك: `pending_payment → active → expired/cancelled`.

## 15.7 مصطلحات تقنية

| المصطلح | المعنى |
| --- | --- |
| **الحُرّاس الثلاثة (Guards)** | `web` (مريض) · `clinic` (مجمع) · `admin` (إدارة). [§12.5](12-architecture.md#125-المصادقة-والعزل-الأمني) |
| **مصدر الحقيقة الواحد** | كل الواجهات تستدعي نفس الخدمات/السياسات. [§12.3](12-architecture.md#123-المعمارية-مصدر-حقيقة-واحد) |
| **مدفوع بسجلّ (Registry-driven)** | إضافة بوابة/شارة جديدة = سطر واحد يظهر في كل الواجهات. [§12.4](12-architecture.md#124-أنماط-معمارية-تسرع-المنتج-مزايا-مؤسسية) |
| **Sanctum SPA** | مصادقة كوكيز ذات حالة. |
| **OTP** | رمز تحقق على الجوال (ينتهي خلال 5 دقائق). [§13.3](13-security-compliance.md#133-دخول-المريض-الآمن-otp) |
| **PII Masking** | إخفاء البيانات الشخصية افتراضياً. [§13.4](13-security-compliance.md#134-حماية-البيانات-الشخصية-pii-masking) |
| **TrackingContext** | مصدر حقيقة واحد للتتبّع المتوافق مع الخصوصية. [§9.7](09-growth-loyalty.md#97-تحويل-الانتباه-إلى-إيراد-التتبع-المتوافق-مع-الخصوصية) |
| **Audit Log** | سجلّ تدقيق بأسماء إجراءات صريحة. [§13.7](13-security-compliance.md#137-سجل-التدقيق-audit-log) |
| **Impersonation** | دخول المشرف كالمجمع للدعم. [§13.8](13-security-compliance.md#138-الانتحال-الآمن-ومساءلة-الفريق) |
| **Reverb / Web Push (VAPID)** | بثّ لحظي / تنبيهات المتصفح. |
| **FeatureGate** | البوابة المركزية لفرض مزايا الباقة. [§10.5](10-business-model.md#105-featuregate--تطبيق-مركزي-للمزايا) |
| **هوية موحّدة (PlatformCustomer)** | عميل واحد عبر المنصة بالهاتف المُطبَّع. [§6.3](06-clinic-crm-operations.md#63-الهوية-الموحدة-للعميل) |
| **نظام البيانات التجريبية (Demo data)** | ختم `is_demo`/`demo_batch` يفصل العرض عن الإنتاج. [§12.4](12-architecture.md#124-أنماط-معمارية-تسرع-المنتج-مزايا-مؤسسية) |
| **حياد المزوّد (AI)** | دعم Gemini/OpenAI/Claude بالتبديل. [§8.5](08-ai.md#85-البنية-محايدة-تجاه-المزود) |
