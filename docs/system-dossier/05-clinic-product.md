# الفصل الخامس — منتج المجمع (لوحة التحكم + CRM)

> [⬅ العودة للفهرس](00-index.md) · الفصل السابق: [رحلة المريض](04-patient-journey.md) · التالي: [منتج الإدارة ➡](06-admin-product.md)

## 5.1 نظرة عامة

لوحة المجمع هي **المنتج المدفوع (SaaS)** — ما يدفع المجمع اشتراكاً شهرياً مقابله. تحوّله من «اسم على خريطة» إلى **متجر رقمي كامل بقناة عملاء وأداة إدارة**. لوحة تفاعلية حديثة (React) تغطّي ثلاث وظائف:

```
1) العرض      ►  ملف المجمع: خدمات · أسعار · عروض · باقات · أطباء · مقالات
2) الطلب      ►  حجوزات (قائمة + كانبان) · طلبات تسعير · شكاوى
3) الإدارة    ►  CRM عملاء · فريق العمل · تحليلات · اشتراك · استيراد
```

---

## 5.2 إدارة المحتوى والعرض

ما يظهر للمريض في [ملف المجمع](04-patient-journey.md#45-ملف-المجمع-الطبي) — كله يُدار من هنا:

| الوحدة | القدرات |
| --- | --- |
| **الخدمات** | إنشاء/تعديل، سعر، فئة (متعدّدة)، عيادة فرعية، ترتيب يدوي (سحب وإفلات)، تفعيل |
| **العيادات الفرعية** | تقسيم المجمع لتخصصات فرعية + ترتيبها |
| **العروض** | عروض ترويجية موقّتة، إبراز، **تمديد** |
| **الباقات الطبية** | حِزم خدمات بسعر مجمّع |
| **الأطباء** | دليل أطباء (مرتبط بالعيادات الفرعية) — *مقيّد بالباقة* |
| **معرض قبل/بعد** | صور النتائج — *مقيّد بالباقة* |
| **المقالات** | محرّر نصّي غنيّ (Tiptap) + صور غلاف + **توليد مقتطف/نص بالذكاء الاصطناعي** — *بحد شهري حسب الباقة* |
| **ساعات العمل** | محرّر أيام/أوقات |
| **الموقع** | استخراج إحداثيات Google Maps |
| **تقييمات Google** | مزامنة — *مقيّدة بالباقة* |

> المزايا الموسومة *«مقيّد بالباقة»* تُضبط مركزياً عبر `FeatureGate` — انظر [الفصل 8](08-business-model.md).

## 5.3 إدارة الطلب — الحجوزات

قلب التشغيل اليومي. الحجوزات تُعرض بطريقتين:

### قائمة
تبويبات حالة + عدّادات، تصدير **CSV**، أدوار محدودة (المجمع يحدّث الحالة/الموعد/الملاحظات فقط).

### لوحة كانبان (Kanban) بأسلوب Odoo
- أعمدة مراحل **قابلة لإعادة التسمية** + سحب وإفلات.
- **وسوم (Tags)** للحجز والعميل.
- **إسناد (Assignee)** لعضو فريق.
- **خط زمني للنشاط** (Activity timeline) لكل حجز + إجراءات سريعة.
- **بطاقة عميل 360°** في اللوحة الجانبية (مفتاحها رقم الهاتف).
- إنشاء حجوزات **Walk-in / تواصل خارجي (Outreach)** وجدولة.

> الحجز الواحد يحمل **رمزاً مرجعياً**، وقد يُنشأ **نيابةً عن قريب**، وكله مسجَّل في خط نشاط — حوكمة تشغيلية حقيقية، لا مجرد قائمة.

## 5.4 نظام إدارة العملاء (CRM)

ميزة تُغني المجمع عن أداة CRM خارجية. **العميل (Customer) سجلّ موحّد لكل مجمع** مفتاحه `(المجمع، الهاتف)`:

- **ربط تلقائي**: كل حجز/شكوى/طلب تسعير يُربط تلقائياً بالعميل المطابق (عبر `CustomerLinker` ومراقِبات).
- **ملف العميل 360°**: خط زمني (حجوزات/شكاوى/تسعير) + إحصاءات.
- **وسوم محسوبة** (VIP، متكرّر، جديد، سبق له شكوى) + وسوم حرّة.
- **سلسلة ملاحظات** متعدّدة (notes thread).
- **مركز عملاء (Customers Hub)** مستقل: قائمة + بحث + ملف.

> هذا يحوّل كل تفاعل عابر إلى **علاقة عميل قابلة للإدارة والاحتفاظ** — قيمة احتجاز (Retention) للمجمع، وقيمة بيانات للمنصة.

---

## 5.5 طلبات التسعير والشكاوى

- **ردود التسعير**: المجمع يردّ على طلبات التسعير الواردة (مع سياق العميل واضغط-للاتصال) — *بحد شهري حسب الباقة*، والرد منسوب لعضو الفريق.
- **صندوق الشكاوى**: استقبال شكاوى المرضى والردّ عليها، بسير حالات (قيد المراجعة/حلّ/رفض/إعادة فتح).

---

## 5.6 فريق العمل والأدوار

المجمع يدعو **أعضاء فريق** بأدوار وصلاحيات مختلفة (موثّق من نظام `clinic.role`):

| الدور | نطاقه (مثال) |
| --- | --- |
| **المالك (Owner)** | كل الصلاحيات |
| **المنسّق (Coordinator)** | إدارة المحتوى (خدمات/أطباء/عروض…) + التشغيل |
| **الاستقبال (Reception)** | الحجوزات/الشكاوى/التسعير اليومية فقط (لا تعديل محتوى) |

- **كل إجراء منسوب ومُسجَّل** (Team Activity) — مساءلة كاملة.
- الصلاحيات تُفرض على مستوى المسار (middleware) لكل وحدة.

> **قيمة مؤسسية:** المجمع المتوسط بعدة موظفين يحصل على **فصل أدوار ومساءلة** — ميزة تبرّر الترقية لباقات أعلى.

---

## 5.7 الاستيراد الذكي للخدمات

تقليل حاجز الإعداد (Onboarding friction): المجمع يستورد خدماته بدل إدخالها يدوياً:

- من **CSV / Google Sheets**.
- من **نص حرّ** عبر الذكاء الاصطناعي (تحليل + استخراج + مطابقة بالكتالوج الموحّد).
- **مراجعة لكل صف** قبل التنفيذ. التفصيل في [الفصل 7](07-ai.md).

---

## 5.8 التحليلات والاشتراك

- **لوحة إحصاءات حيّة** + **شارات تنقّل ذكية** (حجوزات جديدة، اشتراك/عروض توشك على الانتهاء، طلبات تسعير جديدة).
- **صفحة «إحصاءاتي»**: مشاهدات/حجوزات/تسعير عبر فترات (7/14/30 يوماً) + نطاق مخصّص — *بمستوى يحدّده تفصيل الباقة*.
- **صفحة الاشتراك**: الباقة الحالية، الأيام المتبقية، مقارنة المزايا، طلب فئة جديدة من الإدارة.

---

## 5.9 خلاصة الفصل

لوحة المجمع ليست «صفحة تعريف» بل **نظام تشغيل متكامل** (ERP/CRM مصغّر للعيادات): عرض + طلب + إدارة + فريق + تحليلات. وهذا ما يبرّر **الاشتراك الشهري المتكرّر** ويرفع كلفة التحوّل عن المنصة (Switching Cost) — ركيزة في [الخندق الدفاعي](09-moat.md).

> كل ما سبق **مبنيّ ويعمل** ([مرحلة التدشين](01-executive-summary.md#16-ما-الذي-تم-بناؤه-فعلاً-جاهز-مقابل-قادم)) — المتبقّي تفعيل الدفع لتحصيل الاشتراكات ([خارطة الطريق](12-roadmap.md)).
