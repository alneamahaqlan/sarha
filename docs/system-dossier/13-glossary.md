# الفصل الثالث عشر — ملحق: قاموس المزايا والمصطلحات

> [⬅ العودة للفهرس](00-index.md) · الفصل السابق: [خارطة الطريق](12-roadmap.md)

> مرجع سريع لكل المصطلحات والمزايا الواردة في المستند، مرتّبة موضوعياً. عند تكرار مصطلح في فصلٍ ما، يحيل هذا الملحق إليه.

---

## 13.1 مصطلحات النموذج والأعمال

| المصطلح | المعنى |
| --- | --- |
| **المجمع الطبي (Medical Complex)** | الوحدة الأساسية التي يراها المريض؛ قد تضمّ عدّة عيادات/تخصصات فرعية. تُسمّى داخلياً `Clinic`. |
| **العيادة الفرعية (Sub-Clinic)** | تخصص فرعي داخل المجمع. |
| **سوق ثلاثي الأطراف** | منصة تربط ثلاثة أطراف: المرضى (الطلب) + المجمعات (العرض) + الإدارة (المشغّل). [الفصل 3](03-solution-three-sided.md) |
| **دولاب النمو (Flywheel)** | حلقة تعزيز ذاتي: مجمعات أكثر ← مرضى أكثر ← مجمعات أكثر. [§3.3](03-solution-three-sided.md#33-كيف-تتدفق-القيمة-دولاب-النمو) |
| **مرحلة التدشين (Pre-traction)** | المنتج جاهز ويعمل، قبل بدء الجذب التجاري والأرقام الفعلية. [§1.2](01-executive-summary.md) |
| **الخندق الدفاعي (Moat)** | ما يصعّب على المنافس التقليد: شبكة + بيانات + كلفة تحوّل. [الفصل 9](09-moat.md) |
| **كلفة التحوّل (Switching Cost)** | صعوبة انتقال المجمع لمنصة أخرى بعد احتجاز بياناته وعملياته. |
| **تأثير الشبكة (Network Effect)** | ارتفاع قيمة المنصة كلما زاد مستخدموها على الجانبين. |

## 13.2 مؤشرات مالية

| المصطلح | المعنى |
| --- | --- |
| **TAM / SAM / SOM** | السوق الكلي / القابل للخدمة / القابل للوصول. [§2.3](02-problem-opportunity.md#23-حجم-السوق-tam--sam--som) |
| **MRR** | الإيراد الشهري المتكرر (مجمعات نشطة × ARPU). |
| **ARPU** | متوسط الدخل لكل مجمع. |
| **CAC** | تكلفة اكتساب العميل (المجمع). |
| **LTV** | القيمة الدائمة للعميل عبر عمر اشتراكه. |
| **LTV/CAC** | نسبة صحّة النموذج (الهدف ≥ 3). [§8.7](08-business-model.md#87-اقتصاديات-الوحدة-إطار--مرحلة-التدشين) |
| **SaaS** | برمجيات كخدمة باشتراك متكرّر. |
| **Recurring Revenue** | الإيراد المتكرّر المتوقّع. |

## 13.3 مزايا المريض (الموقع العام)

| الميزة | الوصف · المرجع |
| --- | --- |
| **البحث الذكي** | فلاتر (مدينة/تخصص/سعر/تقييم/مفتوح الآن) + 5 خيارات فرز. [§4.3](04-patient-journey.md#43-البحث-والفرز-الذكي) |
| **الفرز بالأقرب** | ترتيب حسب موقع المريض الجغرافي. |
| **المقارنة** | مقارنة عدة مجمعات جنباً إلى جنب. [§4.4](04-patient-journey.md) |
| **الحجز الفوري (OTP)** | حجز مؤكَّد برمز تحقق + رمز مرجعي. [§4.6](04-patient-journey.md#46-التحويل-الحجز-وطلب-التسعير) |
| **التسعير متعدّد المجمعات** | طلب سعر من عدة مجمعات/مدن دفعة واحدة. |
| **حساب المريض** | حجوزات/مفضّلة/تسعير/شكاوى/بلاغات/أقارب. [§4.7](04-patient-journey.md) |
| **المساعد الذكي** | توجيه للتخصص/المجمع مع رفض الأسئلة الطبية. [§7.2](07-ai.md#72-المساعد-العام-للمريض) |

## 13.6 الاشتراكات والمزايا (FeatureGate)

| العمود | النوع | المعنى |
| --- | --- | --- |
| `services_limit` | عدد/∞ | حد الخدمات |
| `articles_monthly_limit` | عدد/∞ | حد المقالات شهرياً |
| `ai_article_generation` | نعم/لا | توليد مقال بالذكاء الاصطناعي |
| `featured_in_search` | نعم/لا | أولوية الظهور بالبحث |
| `ai_assistant_priority` | 0/1/2 | الترتيب في المساعد |
| `google_reviews_sync` | نعم/لا | مزامنة تقييمات Google |
| `verified_badge` | نعم/لا | شارة التوثيق |
| `analytics_level` | basic/full | مستوى التحليلات |
| `quote_replies_monthly_limit` | عدد/∞ | حد ردود التسعير شهرياً |
| `banner_slots` | عدد | بانرات الصفحة الرئيسية |
| `allow_offers_packages` | نعم/لا | العروض والباقات |
| `allow_doctors_before_after` | نعم/لا | الأطباء ومعرض قبل/بعد |

> التفصيل في [§8.4](08-business-model.md#84-مصفوفة-المزايا-موثقة-من-الكود). الحالات: `pending_payment → active → expired/cancelled`.
